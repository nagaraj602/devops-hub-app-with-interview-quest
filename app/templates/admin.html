Admin Access & Cloudflare Tunnel Configuration

Localhost Access

Access the admin portal directly on dedicated port {{ admin_port }} (blocked on public port {{ main_port }}):

http://localhost:{{ admin_port }}/

Docker Desktop Kubernetes routes port 9256 directly to localhost:9256 (NodePort 30956).

Cloudflare Tunnel on GCP

In your Cloudflare Tunnel configuration on GCP (/etc/cloudflared/config.yml) or Cloudflare Dashboard Public Hostnames, route admin.sidorea.shop to port {{ admin_port }}:

ingress:
  - hostname: admin.sidorea.shop
    service: http://localhost:{{ admin_port }}
  - hostname: sidorea.shop
    service: http://localhost:{{ main_port }}
  - service: http_status:404
